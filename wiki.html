Searching in Windows OS

Use the default Windows file management application. Go to > "Installed Files" > "Today".

Launch Mouse/Touchpad

If the shortcut is located at the Start or Main Menu, click Left/Right (depends on your settings) and click on the icon.

If the shortcut is located at the background, double-click Left/Right (depends on your settings) and click the icon.

Launch Touch Screen

If the shortcut is located at the Start or Main Menu, tap on the icon.

If the shortcut is located at the background, double-tap on the icon.

Older Versions Toolkit 25 and Down (BAT)

How to launch the toolkit, and how to use toolkit step-by-step guide.

Start

Tap/click "YES" if a popup is presented.

If text shows: "This File is password protected. Enter the password:"

Enter: 09865TL.

Check host: If you see "Restricted Access," you were chosen for testing unreleased versions. If you see "Host (09865TL)," that's simply your program ID.

How to Use Toolkit

Use actions by pressing the number corresponding to the option in the menu.

After any action is finished, the program will return to the main menu.

For further assistance, contact us on our Discord.

Suggestions

(Toolkit is an open-source project, which means you can suggest new changes to the program.)

How to Suggest Changes

If you want to suggest changes to the program, you have to be a verified member of our Discord server. You can join now!

Option One:

  1. Open your toolkit > type in "C" (our community) or "CH" (check for updates) > Press Enter.
  2. If your default browser pops up, you can close the program.

Option One Trouble Shooting:

  • If this message shows up: "Invalid choice. Press any key to continue..." Please double-check what you typed in (common mistake is not using Caps Lock or holding Shift while typing).
  • Maybe you didn't download "I-FOX Community.html" or rename it. If you do, you can restore the original name by copying and pasting "InnovaDev Community" (Ctrl+C, Ctrl+V).

Option Two:

  1. Open your default browser, type in: https://discord.gg/ujB2UcSXtx to join our Discord community.
  2. Open your default browser, if you don't have Discord, you can download it! Type in: https://discord.com/download.

Option Two Trouble Shooting:

  • Open Task Manager and check if you have enough RAM (we recommend at least 1 GB of free space). Also, we recommend SSD instead of HDD storage type.
  • Also, check your internet connection and you can try moving to a more open area.
  • Maybe you didn't download "InnovaDev Community" or rename it. If you do, you can restore the original name by copying and pasting "I-FOX Community (HTML file)" (Ctrl+C, Ctrl+V).
